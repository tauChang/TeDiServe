\section{Artifact Evaluation}
\label{sec:artifact-evaluation}

The TeDiServe artifact is available at
\url{https://github.com/tauChang/TeDiServe}. It contains the scheduler,
step-time predictor, resource manager, and reconfiguration logic described in
Sections~3--4. The repository README is the authoritative evaluator guide.

\paragraph{Demonstration modes.}
The recommended \emph{smoke mode} runs the real TeDiServe scheduler, control
path, step-time predictor, and measured latency profile with two simulated
model executors. No language model is loaded: the executors return fixed tokens
and confidence values. It therefore validates multi-instance scheduling and
request completion without requiring a GPU, CUDA, model weights, Ray, or
Gurobi, but does not validate model quality or real denoising.

The optional \emph{GPU mode} runs actual LLaDA model inference, checks
the returned responses, and records per-instance work. It was tested on two
GH200 GPUs. This is a short functional demonstration rather than a reproduction
of a paper performance figure. Dynamic reconfiguration is disabled in both
modes, so Gurobi is needed only for separate reconfiguration experiments.

\paragraph{Evaluator workflow.}
The public smoke image supports Linux x86\_64/AMD64 and ARM64/aarch64. The
primary Docker workflow is:

\begin{lstlisting}[language=bash]
docker pull ghcr.io/tauchang/tediserve/tediserve-smoke:2027
mkdir -p artifact-results
docker run --rm --user "$(id -u):$(id -g)" \
  -v "$PWD/artifact-results:/opt/tediserve/artifact-results" \
  ghcr.io/tauchang/tediserve/tediserve-smoke:2027
\end{lstlisting}

Once downloaded, the test takes under one minute and writes a machine-readable
result. Success means all eight requests complete, both instances receive
work, and the result reports a true PASS flag. Podman and Apptainer can run the
same OCI image.

Evaluators with the GPU environment described in the README may additionally
run:

\begin{lstlisting}[language=bash]
bash artifact/run_demo.sh --mode gpu --instances 2 --requests 8 \
  --output-dir artifact-results/gpu
\end{lstlisting}

\paragraph{Scope.}
The artifact exercises the central implementation path: deadline-aware request
scheduling across model instances using the learned step-cost predictor. It
retains the measured LLaDA and Dream profiles used as scheduler inputs. It does
not package every paper-figure workflow, long trace replay, or full baseline
comparison, which require large traces, multi-GPU clusters, and long runs.
